# 🌦 云上晴雨天气台

**宫崎骏风格 Windows 桌面天气插件 · 实时天气 + 昼夜地球 + 万年历 + 吸顶小窗 + OTA 在线更新**

一个透明无边框的桌面天气小部件（Electron）。抬头看天、低头看雨——实时天气、分钟级降水、昼夜地球与万年历都在一块「玻璃」上；拖到屏幕顶端收起成温度小窗常驻桌面，日落后整块界面自动换上星空夜色。

![预览](preview.png)

## ✨ 功能一览

### 🌤 天气与预报

- 🌡 **实时天气**：温度、体感、湿度、风力、气压、能见度，空气质量（PM2.5 / AQI）
- 🕐 **预报**：未来 24 小时逐时 + 7 日预报，穿衣 / 出行 / 紫外线等生活指数
- 🌧 **分钟级降水**：未来 2 小时逐 15 分钟降水柱状图 + 智能摘要（「约 X 分钟后开始下雨 / 雨约 X 分钟后停」）
- 📣 **天气提示条**：雷雨 / 降雨 / 降雪点名到具体哪一天；高降水概率自动与该日降水量、天气码交叉校验，按证据强弱措辞，不误报不吓人
- 📈 **温度趋势**：24 小时温度曲线叠加降水概率，横轴带时间刻度与参考线，和逐时卡片逐点对得上
- 🌅 **朝晚霞概率**：下一次日出 / 日落的云况评估，绝佳 / 不错 / 一般 / 难见 四档
- 📍 **精准定位**：定位与搜索精确到区县 / 街道，支持多地点切换

### 🌍 昼夜地球

- 🛰 3D 自转球体，真实晨昏线与昼夜分布，日出 / 日落 / 月出 / 月落四宫格（淡彩氛围底色）
- 🖱 鼠标拖拽 360° 旋转球体，昼夜覆盖随视角实时调整，双击复位
- ⏱ 时间进度条可拖动，拨动即模拟一天中的任意时刻
- 🔄 「演示自转」（45 秒 / 圈）与「真实自转」一键切换，切回真实自转即全复位

### 📅 万年历

- 📆 农历、宜忌、吉日
- 🏮 法定节假日「休 / 班」标注（跟随国务院安排）

### 🪟 桌面体验

- 📌 **顶部吸附**：拖到屏幕顶端自动收起为温度小窗，悬停展开；小窗位置跟随大窗平移，重启按记忆还原
- 🌙 **夜色星空主题**：按当地日出日落自动切换深色星空配色，日出自动恢复
- 🌡 **托盘温度**：系统托盘实时显示当前温度，昼夜配色自动切换
- 📣 **天气早晚报**：每天 8:00 / 20:00 系统通知播报天气与带伞提醒（可关闭）
- ⚡ 开机自启、窗口置顶、数据本地记忆
- 🧩 **模块开关**：昼夜地球 / 逐时预报 / 七日预报 / 空气质量 / 生活指南 / 万年历 均可独立开关，按需精简界面

### 🔄 OTA 在线更新

- 📡 启动 30 秒后首检，之后每 4 小时后台检查
- 🆕 发现新版本横幅提醒 →「立即更新」后台下载 →「立即重启」完成安装
- ✅ sha512 校验，校验失败自动回退全量下载

## 🚀 快速开始

### 下载安装

前往 [Releases](https://github.com/kmnn111/sky-weather-widget/releases) 下载最新的 `SkyWeather-Setup-x.y.z.exe`，双击安装即可。装好后常驻托盘，可在设置里开关开机自启、窗口置顶。

### 开发与构建

```
git clone https://github.com/kmnn111/sky-weather-widget.git
cd sky-weather-widget
npm install        # 安装依赖
npm start          # 开发运行
npm run dist       # 打包 NSIS 安装包 → dist/云上晴雨天气台-Setup-x.y.z.exe
```

数据源（国内直连、免密钥）：[Open-Meteo](https://open-meteo.com)（天气 / 空气）、[Nominatim](https://nominatim.org)（地名）。

### OTA 更新部署

发新版时，把 dist 目录下 **3 个文件**上传到同一个 HTTP(S) 目录（或 GitHub Release）：

| 文件 | 说明 |
| --- | --- |
| `latest.yml` | 更新元数据（版本号、校验和） |
| `SkyWeather-Setup-x.y.z.exe` | 安装包本体 |
| `SkyWeather-Setup-x.y.z.exe.blockmap` | 差分更新块映射（可选，缺失则全量下载） |

> 用 GitHub Release 作更新源时，资产名请使用 ASCII（如 `SkyWeather-Setup-x.y.z.exe`）——中文文件名在 `/releases/latest/download/` 直链下会 404。仓库脚本产出的 `dist-gh/` 即为可直接上传的 ASCII 三件套。

用户端两种接入方式：

1. **内置更新源**（推荐）：`main.js` 的 `DEFAULT_UPDATE_URL` 已内置 GitHub Releases 直链，装好即自动收到更新提醒（也可打包前改为自己的目录地址）；
2. **手动配置**：在 设置 → 软件更新 里填写更新服务器地址。

```
└── dist/               # npm run dist 产物（安装包 + latest.yml）
```

## 📝 常见说明

- **小窗记忆**：吸顶小窗位置跟随大窗平移自动对位，重启后按记忆位置还原。
- **夜色切换**：按当地日出日落精确翻转（以天气数据 sunrise / sunset 为准），不按固定钟点猜。
- **更新横幅**：点「稍后」后同一版本只提醒一次；设置 → 软件更新 里可随时手动检查，已下载的更新可「立即重启」安装。
- **调试自检**：`--shot` / `--shot-globe` / `--shot-update` / `--shot-dock` 为开发自检入口，日常使用无需关心。
